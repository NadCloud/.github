# NadCo

NadCo builds and operates software products and infrastructure for businesses in Iran.

## Business units

| Unit | What it does |
|---|---|
| **NadStore** | E-commerce storefronts and ongoing support for online stores |
| **NadEdu** | Management system for educational institutes |
| **NadCloud** | Shared internal services (media hosting, notifications) used across our products |

## How we work

- All changes go through pull requests. `main` is protected.
- Commits and PR titles follow [Conventional Commits](https://www.conventionalcommits.org/).
- Every repository has a README with setup, configuration, and deployment notes.
- Naming, branching, and review rules live in [CONTRIBUTING.md](../CONTRIBUTING.md).
